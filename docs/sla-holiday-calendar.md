# تقویم تعطیلات SLA

تقویم کاری `IR_STANDARD_WORK_WEEK` از شنبه تا چهارشنبه، ساعت ۰۸:۰۰ تا ۱۷:۰۰
در منطقه زمانی `Asia/Tehran` محاسبه می‌شود. تعطیلات رسمی سال ۱۴۰۵ از تقویم رسمی
دانشگاه تهران استخراج شده‌اند:

- منبع رسمی: https://calendar.ut.ac.ir/documents/2139738/7092644/Calendar-1405.pdf
- بازه پوشش داده: ۱۴۰۵/۰۱/۰۱ تا ۱۴۰۵/۱۲/۲۹
- تعداد روزهای تعطیل ذخیره‌شده: ۲۷

تعطیلی‌های موقت استانی یا مصوبات موردی دولت در این مجموعه ثابت قرار نمی‌گیرند و باید
به‌صورت تغییر داده ممیزی‌شده به نسخه جدید تقویم اضافه شوند. پیش از شروع هر سال شمسی،
عملیات باید تقویم رسمی سال بعد را در نسخه جدید وارد کند؛ snapshot تیکت‌های قبلی نباید
بازنویسی شود.

برای کنترل پوشش دیتابیس اجرا کنید:

```bash
npm run verify:sla-calendar
```
